# Ассеты и лицензии

Заполняйте по мере добавления файлов в `game/assets/`.

| Файл / папка | Автор | Лицензия | Ссылка |
|--------------|-------|----------|--------|
| *(пример)* `tiles/tile_bamboo.png` | Your name | CC0 / own work | — |
| `audio/music/aurora_ambient_loop.wav` | Aurora Pulse project | Own work | generated by `scripts/generate_audio.py` |
| `audio/sfx/*.wav` | Aurora Pulse project | Own work | generated by `scripts/generate_audio.py` |

**Правило:** только оригинальные работы или лицензии, разрешающие использование в open-source игре (CC0, CC-BY с указанием автора, Kenney.nl и т.д.).
