# Aurora Pulse — Style Guide

Единый язык визуального дизайна для всей игры. Любой новый экран, кнопка или анимация должны вписываться в эту стилистику. Источник правды для агентов и для художника, который придёт делать финальные ассеты в Фазе 3.

---

## 1. Концепция

**Aurora Pulse** — медитативный triple-match маджонг в эстетике северного сияния. Игрок «гасит огни» в ночном небе, складывая тройки. Атмосфера:

- спокойствие, минимализм, отсутствие давления (нет таймеров в MVP);
- тёмный космический фон с мягким свечением;
- яркие, насыщенные плитки как «всплески сияния» на фоне ночного неба;
- лаконичный UI без визуального шума.

**Эмоция:** «тихий восторг, когда совпало». Не казуальная мобильная аркада с миллионом частиц, а лаконичный пазл.

## 2. Палитра

### Фон (background stack)

| Назначение | HEX | Где используется |
|------------|------|------------------|
| Deep Night (база) | `#0B0E2A` | базовый цвет окна, низ градиента |
| Aurora Violet | `#241B45` | середина градиента |
| Aurora Cyan Glow | `#1B4A6A` | верх градиента, лёгкое свечение |
| Star Mist (overlay) | `#FFFFFF` @ 4% | звёздная пыль / шум |

Фон — вертикальный градиент сверху вниз: `Cyan Glow → Violet → Deep Night`. Поверх можно положить лёгкий шум или несколько белых точек = звёзды.

### Плитки — 3 масти (suits)

Каждая масть — отдельная семья цветов. Все плитки **сплошной заливкой** + крупная белая цифра ранга (1–9). 27 уникальных типов = 3 цвета × 9 цифр.

| Масть | Внутреннее имя | Базовый HEX | Семантика |
|-------|----------------|-------------|-----------|
| Bamboo | `bamboo` | `#3ECF8E` (emerald) | «зелёный пульс» — рост, свежесть |
| Circle | `circle` | `#4DA8FF` (sky blue) | «синий пульс» — вода, спокойствие |
| Char | `char` | `#FF6B9D` (rose) | «розовый пульс» — тепло, энергия |

Внутри одной масти ранг **не меняет цвет** — только цифра. Это сознательно: визуальный группировщик — цвет, идентификатор — цифра. Если игроку нужно найти три одинаковых — он сначала сканирует по цвету, потом по цифре. Так быстрее, чем 27 разных оттенков.

### Состояния плитки

| Состояние | Изменение от базового | Зачем |
|-----------|----------------------|-------|
| Free (можно кликать) | без изменений | базовый яркий вид |
| Blocked (перекрыта сверху) | серый/тёмный тинт усиливается от 1 до 4 перекрытий | визуальная сигнализация «нельзя» |
| Hover (mouse) | `position.y -= 6`, лёгкая белая обводка | курсорная подсказка |
| Selected (в слоте) | `scale = 1.08`, white outline | подтверждение выбора |
| Shake (ошибка/блок) | `position.x` качается ±8 px за 0.25 с | тактильная обратная связь |
| Clear (победа тройки) | `scale → 0`, `modulate.a → 0` за 0.3 с | растворение |

### UI акценты

| Назначение | HEX |
|------------|------|
| Текст основной | `#F0F4FF` (почти белый) |
| Текст вторичный | `#9AA3C7` (приглушённый сиреневый) |
| Аккент / прогресс / победа | `#7CF5FF` (cyan glow) |
| Ошибка / shake | `#FF5A5A` |
| Поверхность кнопки | `#1A1F45` |
| Поверхность кнопки hover | `#2A3070` |
| Слот выбора (пустой) | контур `#9AA3C7`, fill прозрачный |
| Слот выбора (заполнен) | подсветка `#7CF5FF` 12% |

## 3. Типографика

- **Заголовок (Aurora Pulse, экран победы):** 96 pt, bold, цвет `#F0F4FF`, легкое cyan-свечение через тень.
- **Подзаголовок / уровень:** 40 pt, regular.
- **Кнопки:** 44 pt, semi-bold.
- **Цифра ранга на плитке:** 72 pt, bold, `#F0F4FF`. На некоторых мастях (особенно `bamboo`) — цвет можно сделать `#0B0E2A` для контраста, но в MVP белый ОК на всех трёх.
- **HUD (очки, прогресс):** 32 pt, regular.

Шрифт — системный (Godot default) в MVP. В Фазе 3 — заменить на что-то rounded sans-serif (Inter, Manrope, Quicksand). Кириллица обязательна.

## 4. Геометрия и размеры

Базовый viewport: **1080 × 1920** (portrait). Все размеры ниже — в этой системе.

| Элемент | Размер | Комментарий |
|---------|--------|-------------|
| Плитка | **160 × 200** | пропорции маджонг-плитки 4:5, скруглённые углы радиус 24 |
| Half-cell (шаг сетки) | **84 × 104** | плитка занимает 2×2 half-cells; даёт 8 px margin между соседями |
| Layer offset (визуальный «лифт» верхних слоёв) | dx = -6, dy = -10 | подъём вверх-влево, имитация 3D |
| Слот выбора | **180 × 220** | чуть больше плитки, с пунктирной рамкой |
| Главная кнопка | min 140 px высоты, padding 32 px | touch-friendly ≥ 96 px по плану |
| Margin безопасной зоны | 48 px сверху/снизу, 32 px по бокам | edge-to-edge без обрезаний |
| Радиус скругления | 24 px (плитки), 28 px (кнопки), 16 px (панели) | единый «soft» язык форм |

**Координатная система пирамиды (важно для генератора)** — half-step grid. Каждая плитка имеет `(grid_x, grid_y, layer)`, где `grid_x`, `grid_y` — индексы в half-step единицах:

- L0-плитка `(c, r)` сидит на `(c*2, r*2)` в half-step.
- L1-плитка смещена на `+1` half-cell — её координаты `(c*2 + 1, r*2 + 1)`. Одна L1 перекрывает 4 угловые L0-плитки → классический «mahjong staircase».
- L2 на `+2` half-cell относительно L0.
- Перекрытие сверху: `|dx| < 2` И `|dy| < 2` в half-step.

Тень: всем поднятым элементам (плитки, кнопки, слоты) — мягкая тень `Color(0, 0, 0, 0.35)`, offset `(0, 6)`, blur 12 px (если StyleBoxFlat поддерживает — через `shadow_size`, `shadow_offset`).

## 5. Анимации

Все анимации делаются через `Tween` с easing **`EASE_OUT`**, transition **`TRANS_BACK`** или **`TRANS_QUAD`** — мягкие, без резких отскоков.

| Событие | Анимация | Длительность |
|---------|----------|--------------|
| Hover плитки | `position.y -= 6` + outline alpha 0→1 | 0.12 s |
| Click free-плитки | scale 1.0→1.08, reparent в слот, tween position to slot center | 0.22 s |
| Click blocked-плитки | shake x ±8 px, 4 цикла | 0.25 s |
| Тройка совпала | scale 1.0→0, alpha 1→0, slots мигают cyan | 0.3 s |
| Тройка НЕ совпала | каждая плитка shake + tween position обратно на доску | 0.3 s |
| Уровень завершён | прогресс-бар flash cyan, оверлей fade-in 0.4 s | 0.4 s |
| Появление новой раскладки | плитки stagger fade-in (по 0.04 s каждая, max 0.6 s) | up to 0.6 s |

Звук в MVP не реализован, но в коде сигналы должны эмититься — потом подвяжем SFX (Фаза 3): `tile_clicked`, `tile_blocked`, `triple_matched`, `triple_failed`, `level_completed`.

## 6. Слой / порядок отрисовки

В одном слое (layer) z-порядок плиток определяется их `grid_y` (нижние ряды поверх верхних — иначе нижние перекроют верхние). В разных слоях — `z_index = layer * 10`.

При reparent в слот плитка должна оказаться поверх всех остальных — устанавливаем `z_index = 1000` пока в слоте, возвращаем при unparent.

## 7. UX-инварианты

Из ТЗ (`tz.md`), не нарушать:

1. **Игрок всегда видит**, можно ли нажать плитку (free / blocked — визуально разные).
2. **Игрок всегда видит**, что выбрано — слоты на экране, плитки в них.
3. **Игрок всегда понимает, почему действие не сработало** — shake + serое плитки = «заблокирована».
4. Только касания / клики — никаких обязательных хоткеев в release.
5. Минимальный touch-target ≥ 96 px (наша плитка 160×200 — с запасом).
6. После любого действия не дольше **0.3 s** до видимой обратной связи.

---

## 8. Что НЕ делать

- Не использовать яркие красные / оранжевые цвета на фоне (они выбьют северное сияние). `#FF5A5A` только для error-shake.
- Не добавлять текстуры дерева / камня на плитки. Aurora — про чистые цвета, не про реалистичный маджонг.
- Не делать декоративных рамок вокруг плиток — только скруглённый сплошной цвет + цифра.
- Не использовать sans-serif с засечками. Только rounded / humanist.
- Не делать длинных анимаций > 0.6 s — игра должна ощущаться отзывчивой.
- Не показывать модальные диалоги «Вы уверены?» — все действия обратимы или не разрушительны.

## 9. Имплементация в коде

Все цвета и числа из этого документа должны жить в одном месте — `game/scripts/rules/tile_types.gd` (палитра мастей) и в темовых StyleBox-ах при их добавлении в Фазе 3.

Сейчас (MVP) StyleBox-ы создаются программно в `tile.gd` / `board.gd` — рефакторить в `theme.tres` после стабилизации геймплея.

**Когда правишь стиль — обнови этот файл.** Он — источник правды.
